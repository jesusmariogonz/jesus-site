# Mi sitio personal — Next.js + Vercel

Sitio personal con blog por categorías, currículum en PDF, proyectos y contacto.

## Comandos rápidos

```bash
npm install     # instalar (solo la primera vez)
npm run dev     # ver el sitio en http://localhost:3000
npm run build   # verificar que todo compila
```

## Publicar una nota

1. Crea `content/blog/nombre-de-la-nota.md`
2. Copia el frontmatter de cualquier nota existente y escribe.
3. `git add . && git commit -m "nueva nota" && git push`
